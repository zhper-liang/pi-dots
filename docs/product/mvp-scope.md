# MVP 能力与限制

本地单用户的核心闭环已交付，这不等于完整产品或商用承诺。本文只列“能做什么、边界在哪”；规则本身在各架构文档，验收状态在 [NEXT_STAGE](../../NEXT_STAGE.md)。

## 能做什么

| 能力 | 支持 | 不能误报的边界 |
|---|---|---|
| 对话 | 每个机器人一个主会话，另可开独立任务；真实模型、多轮工具调用、排队与插入、取消、Skill 按需使用、上下文压缩、Markdown 回复 | 主会话只能清空换新；删除不物理擦除审计 |
| 机器人 | 只填名字即可创建，默认空白；能力三栏开关实时生效；主管可在对话里管理机器人 | 主管不能停用自己；停用后历史只读 |
| 协作 | 委派、验收与返工（最多两次）、阻塞上报、群聊单目标 @、带来源的共享信息 | 主管不能代用户确认 |
| 本机能力 | 每个机器人自带 bash / read / write / edit，用服务进程的系统权限 | 不按脚本内容识别删除；中断后结果不明不重放 |
| 本地日程与待办 | 网页增删改不经过模型；版本冲突检查；日历日 / 周 / 月视图和桌面拖动改期 | 不支持全天和重复事件写入；删除不级联；窄屏不做触屏拖动 |
| 飞书日历 | 一个显式绑定的应用日历；窗口查询、精确读取、普通事件增删改 | 邀请、会议室、重复与例外、全天写入拒绝；外部写入不能撤销；无原子 CAS 或 exactly-once |
| Google（待验收） | Calendar、Tasks 原生；Gmail、Drive、Docs、Sheets 经 workspace-mcp | 只测过假服务，真实账号未手测；workspace-mcp 写入结果无法自动核实 |
| 外部 MCP | Streamable HTTP 或本机已安装的 stdio 程序；对话里可由主管配置 | 不是任意安装器，不做通用 OAuth；凭据只从安全表单输入 |
| 计划与例行任务 | 一次 / 每天 / 工作日 / 每周 / 每月 / 间隔，时区和夏令时；事件触发；测试运行 | 不是完整 cron；最多 200 个计划；暂停不补跑；后台进程必须在线 |
| 同步 | 后台只读重扫外部窗口，记录版本、coverage、缓存时间 | 不完整或过期时不宣称完整；移出窗口不等于删除 |
| 提醒与收件箱 | 目标版本失效重算、发送前核对、持久记录 | 没有系统推送或 Web Push；已读不等于收到 |
| 主动发现 | 冲突、逾期、会前未准备、话题跟进、昨日遗留；“帮我想办法”只读分析（默认关） | 检测不调用模型；每天最多 10 张卡；夜间只进收件箱 |
| 记忆 | 每个机器人的人格和记忆文件、共享偏好；对话里改；后台按会话一小时空闲或压缩时整理；主会话搜索同机器人历史；验证过的方法学成本机器人的 Skill | 不承诺无遗漏；真实模型下的整理质量未评估；日程不进记忆 |
| 模型 | 多个供应商登记，新建机器人可选；容量可填，默认 256K | 改模型名需要重新选择，不自动回落 |

## 运行条件和不承诺

- 后台进程必须在线，网页可以关；停机期间不执行。
- 一个后端独占一个 SQLite 库；只绑定 127.0.0.1，单机单用户，没有多租户隔离。
- 外部结果不明就保留 `unknown`，不自动重试。
- 没有云端部署、手机 App、系统推送和支付。

运行和故障处理见[运行手册](../engineering/operations.md)。
