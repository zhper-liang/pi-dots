# MVP 能力与限制

早期MVP基线：2026-10-24（Asia/Shanghai）；本页已同步R1实际实现，本轮本地验收结果及待用户验收见[验收材料](../../plans/active/workspace-experience-r1/ACCEPTANCE.md)。权限已按 [ADR-014](../decisions/README.md#adr-014-实时权限与直接做先问) 简化，既有写入确认规则见 [ADR-015](../decisions/README.md#adr-015-工具组默认开开即直接做)；R1 已将新 Bot 改为空白业务能力，并分离启停与确认。本地单用户核心闭环 MVP 已交付；这不等于完整产品愿景或正式商用承诺。

## 多 Bot 与协作
- 独立 Bot 与持续会话、版本化模型/提示词配置，工具、资源和规则按当前分配实时生效。
- Chief 受控管理、跨 Bot 委派、阻塞上报、结果验收与返工。
- 群聊、管理员、显式定向 @、稳定目标ID与来源责任追踪；私聊换目标带草稿而不自动发送。
- 持久 Task、输入队列、安全插入、调用预算、精确审批与恢复。
- 建 Bot 只需名字；不按名字推断人格/业务职责，新 Bot 的工具、MCP/Skill 分配及来源资源默认空白，无能力仍可正常聊天。建完进入其主会话；高级参数可选，工具/Skills/MCP/记忆/设置保留独立入口。旧 Bot 原配置、来源与撤销保留，不重启灌满权限。
- 每个 Bot 一个主会话：带 Bot 当前全部可用工具，可直接读写；长任务用 task_create 派给自己的独立任务（不等待）。新增、撤销、重授工具对已有 Task 下一次调用生效，不把运行配置快照当权限；历史与结果实时复核，外部来源失效后旧派生上下文可退役。派生任务的审批、补充、提案、自动执行和结束以系统卡显示在主会话；结束概述下一轮带入、成功回复后删除；主会话按输入计额；不走普通取消/删除，而以明确“清空并开始新会话”替换当前入口，旧详情410、新上下文空、Bot及独立子Task保留，结果向当前主会话接续。普通会话可停止并持久删除；审计不物理擦除，Bot停用后只读。
- 首页 = Chief 主会话；事项默认日历，独立待办页与今日待办块收起，既有Todo数据/API保留（在首页输入即发给 Chief 主会话，不再每句新建任务）；会话、镜像卡、收件箱里的审批/补充/发现/自动执行等用同一套系统卡和按钮规则；每个会话顶部可切到“时间线”（模型回合、工具调用摘要与原文、结果、审批、补充、结束）；等你处理的卡固定在输入框上方。

## 本阶段简化界面与记忆
- 事项常驻日历与自动化，独立待办UI收起而数据/API保留；日历用卡片和日期时间选择器，点日程编辑，不宣称触屏拖动。改期冲突显示当前版本重新确认，断线保留原请求身份；飞书日历仍按来源权限只读。
- 例行任务支持一次/每日/每周/每月/间隔/事件；短月取月末。时区、可选模型及通知沿用简单表单，高级写入选项折叠。
- 设置页可保存模型地址、模型名和新 key；key 不回显，环境变量来源整块只读。主会话输入框可为下一条消息选择已配置模型，独立 Task 只读其模型快照。
- Bot「记忆」页编辑人格、纠正/删除有来源记忆；人格替代原职责编辑。用户偏好跨 Bot 共享，只在设置页修改。空闲合并提取有独立额度，失败显示待处理，日程始终以实时日历为准，不承诺完整无遗漏长期记忆。

## 能力配置与 Skill

受权 Chief/配置 Agent 可用 mcp_manage/skill_manage 解析明确来源、登记、绑定并核对真实状态；初始意图、全局影响及必要机制授权使用精确宿主确认。缺凭据通过安全UI输入后续办同一原Task/输入，不把Key放进聊天或模型参数。新登记不是自动分配，Skill正文/allowed-tools也不授权业务工具；声明式导入固定版本，运行Task快照保留，必要scripts显示缺依赖、不执行。未知操作只核对原请求回执，不因相同catalog内容推测成功或自动重派。

## 运行条件与非承诺
后台进程必须在线；网页可关闭。一个后端独占一个 SQLite 库。仅本机单 owner，不提供多租户隔离产品保证；历史真实跨租户验收豁免不转为通过。

外部 provider 不提供原子 CAS 或通用 exactly-once 保证；unknown 必须保留。通知 recorded/read 不代表用户实际收到。没有云端部署、手机 App、Web Push、邮件/外部待办连接器、支付和完整长期记忆系统。
