# MVP 能力与限制

早期 MVP 基线为 2026-10-24；当前界面和权限已按第四轮 [ADR-022](../decisions/README.md#adr-022-工具集只有开关来源跟着日程与待办新机器人带默认能力) 收简。第四轮实现与实际验证见[计划](../../plans/active/r4-simplify/README.md)，第三轮 Google 仍待用户真实账号验收。本地单用户核心闭环已交付，不等于完整产品或正式商用承诺。

## 多 Bot 与协作
- 独立 Bot 与持续会话、版本化模型/提示词配置，工具、资源和规则按当前分配实时生效。
- Chief 受控管理、跨 Bot 委派、阻塞上报、结果验收与返工。
- 群聊、管理员、显式定向 @、稳定目标ID与来源责任追踪；私聊换目标带草稿而不自动发送。
- 持久 Task、输入队列、安全插入、调用预算、精确审批与恢复。
- 建机器人只需名字，可选职责、模板和高级能力。默认「日程与待办」「历史与回读」开启，Skills / MCP 关闭；可在创建时覆盖。点机器人进对话，齿轮进「能力 / 记忆 / 设置」，高级可收窄日历和任务列表。
- 每个 Bot 一个主会话：带 Bot 当前全部可用工具，可直接读写；长任务用 task_create 派给自己的独立任务（不等待）。新增、撤销、重授工具对已有 Task 下一次调用生效，不把运行配置快照当权限；历史与结果实时复核，外部来源失效后旧派生上下文可退役。派生任务的审批、补充、提案、自动执行和结束以系统卡显示在主会话；结束概述下一轮带入、成功回复后删除；主会话按输入计额；不走普通取消/删除，而以明确“清空并开始新会话”替换当前入口，旧详情410、新上下文空、Bot及独立子Task保留，结果向当前主会话接续。普通会话可停止并持久删除；审计不物理擦除，Bot停用后只读。
- 首页 = Chief 主会话；事项默认日历，独立待办页与今日待办块收起，既有Todo数据/API保留（在首页输入即发给 Chief 主会话，不再每句新建任务）；会话、镜像卡、收件箱里的审批/补充/发现/自动执行等用同一套系统卡和按钮规则；会话详情的技术信息可打开“时间线”（模型回合、工具调用摘要与原文、结果、审批、补充、结束）；等你处理的卡固定在输入框上方。

## 本阶段简化界面与记忆
- 事项为日历、定时任务、执行记录三栏；定时任务统一列出所有机器人的任务。通知为「需要你处理」「提醒」，诊断与管理字段折叠。
- 全局设置为连接、模型、自动化、偏好、高级五块，飞书 / Google / MCP 集中连接；本机 stdio 凭证与技术状态在高级。
- 机器人设置为能力、记忆、设置；对话标题栏只保留标题、忙碌/等待状态、归档、齿轮和详情。工具名显示中文，模型与思考深度收进输入框「⋯」。
- 定时任务支持一次/每日/每周/每月/间隔/事件；短月取月末，暂停不补跑；高级写入选项保留。
- 模型 key 不回显，环境变量设置只读；主会话下一条消息可选模型，独立 Task 模型名保留在详情技术信息。
- 人格、记忆和共享偏好沿用文件式记忆与来源校验；空闲批处理有独立额度，日程始终实时读，不承诺无遗漏长期记忆。

## 能力配置与 Skill
- 「能力」按 Skills / MCP / 工具集三栏列出本机已装、已连接能力，带搜索，每项一个开关；不做在线市场、不再设置写入确认模式。
- 新机器人默认开启「日程与待办」「历史与回读」，创建请求可覆盖；日历与待办工具合并，连接自动分发给开着该工具集的机器人，收窄后重连不恢复。
- 开任一 Skill 自动附带加载工具，关最后一个后移除；Skill 正文与 allowed-tools 不授予业务工具或日历许可。模拟日程不再出现在界面，后端及测试保留。
- 已授权 Chief / 配置 Agent 仍可用 mcp_manage / skill_manage 登记、绑定并核对真实状态；按 ADR-018 / ADR-022 直接执行，全局暂停时确认。凭据只从安全表单输入，同一原操作续办，unknown 不自动重派。

## 运行条件与非承诺
后台进程必须在线；网页可关闭。一个后端独占一个 SQLite 库。仅本机单 owner，不提供多租户隔离产品保证；历史真实跨租户验收豁免不转为通过。

外部 provider 不提供原子 CAS 或通用 exactly-once 保证；unknown 必须保留。通知 recorded/read 不代表用户实际收到。没有云端部署、手机 App、Web Push、邮件/外部待办连接器、支付和完整长期记忆系统。
