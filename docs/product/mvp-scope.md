# MVP 能力与限制

版本基线：2026-10-24（Asia/Shanghai），权限已按 [ADR-014](../decisions/README.md#adr-014-实时权限与直接做先问) 简化。本地单用户核心闭环 MVP 已交付；这不等于完整产品愿景或正式商用承诺。

## 多 Bot 与协作
- 独立 Bot 与持续会话、版本化模型/提示词配置，工具、资源和规则按当前分配实时生效。
- Chief 受控管理、跨 Bot 委派、阻塞上报、结果验收与返工。
- 群聊、管理员、单目标 @、来源上下文和责任追踪。
- 持久 Task、输入队列、安全插入、调用预算、精确审批与恢复。
- 建 Bot 只填名字：职责按名字套固定模板（不调模型，同名同结果），默认勾选本地 workspace.list/get/prepare_change/operation_status 与 workspace:local，新建/修改直接做、删除先问；建完直接进入它的主会话；其余设置收在“高级”。Chief 在对话里也只需名字，建完可以派任务把活交给它。
- 每个 Bot 一个主会话：带 Bot 当前全部可用工具，可直接读写；长任务用 task_create 派给自己的独立任务（不等待）。新增、撤销、重授工具对所有已有 Task 的下一次调用生效，不再刷新许可快照或截断模型历史；历史与工具结果仍实时复核。派生任务的审批、补充、提案、自动执行和结束以系统卡显示在主会话；结束概述下一轮带入、成功回复后删除；主会话按输入计额，不能取消，Bot 停用后只读。
- 首页 = 可折叠的“今天”摘要 + Chief 主会话（在首页输入即发给 Chief 主会话，不再每句新建任务）；会话、镜像卡、收件箱里的审批/补充/发现/自动执行等用同一套系统卡和按钮规则；每个会话顶部可切到“时间线”（模型回合、工具调用摘要与原文、结果、审批、补充、结束）；等你处理的卡固定在输入框上方。

## 工作区能力
|能力|支持|不可误报的边界|
|---|---|---|
|本地待办/普通定时日程|认证UI无模型CRUD、显式关联、版本冲突、持久Operation|待办截止不占日历；删除不级联；不支持全天/重复写|
|飞书应用日历|一个显式绑定账号/容器；真实窗口查询/精确get；普通事件按精确参数与规则CRUD，默认新建/修改直接做、删除先问|外部权威，缓存不是写回；无原子CAS/exactly-once；邀请/会议室/重复/例外/全天写拒绝；对外写入不可撤销|
|来源与权限|本地所有者隐式完整许可；外部来源保留用户 Grant/readScope；Bot 页统一工具/资源勾选与规则；最具体规则优先，同级 deny > ask > allow，默认仅删除先问；busy-only 投影、实时撤权、统一收件箱；全局暂停、本地自动改动可撤销|仅本机单 owner；无能力池、Bot Grant、档位、权限快照、风险分级、批量/小时自动写入上限。Chief 默认直接创建/配置 Bot（含自身配置），停用先问，不能停用自身；暂停中写入 allow 降为 ask。审批卡可选“本次/以后直接做/拒绝”，暂停与 unknown 后重做不提供“以后直接做”；模型/工具/token 预算保留|
|MCP|固定2025-11-25协议，内部 host 会话、本机 stdio 受限 client；设置页发放/列出/撤销凭证|不是公网 HTTP MCP；凭证不进模型；client 受 sources/actions/readScope、到期、撤销、用户许可及 Bot 当前分配约束，写入按同一规则裁决；workspace.prepare_schedule 仍只返回不可执行草案，routine_propose 默认直接建例行任务|
|持久计划|一次性/每日/≥60秒间隔、时区/DST、暂停/恢复/取消、Occurrence 历史；Bot 页管理和测试运行，对话 routine_propose 默认直接创建；事件触发：待办到期、日程变更、本 Bot 任务结束；writes=true 按当前分配及规则执行工作区改动，本地自动改动可撤销；无人值守遇到 ask 跳过并记明“需要你来做”，不出审批卡等过期；结果可“接着聊”|不是完整 cron/RRULE；200计划/1000扫描预算；暂停不补跑。派发实时检查 Bot active、读工具及来源资源/许可，失效取消并记录原因；改配置版本本身不取消；旧只读计划和测试仍只读，取消不撤销已发生外部效果|
|同步|后台只读窗口重扫、版本/coverage/缓存时间、失败30/120秒最多3次|停机不执行；不完整或过期不宣称完整；移出窗口不同于删除|
|主动提醒|冲突、逾期、会前未准备、话题跟进（等你补充/审批/确认、等主管验收超过4小时）、每日昨日遗留；推到Chief主会话并留在收件箱；处理/忽略/这类别再提醒；设置里可打开“帮我想办法”（默认关闭）：Chief 开只读任务分析并给方案，结论显示在主会话完成卡上，可勾选让 Chief 只读查看本地待办和日程|检测本身纯代码不调模型；“帮我想办法”每次最多 5 次模型、10 次工具；每天最多10张卡、夜间只进收件箱；外部来源数据不全或过期时不参与；需后台进程在线|
|关联提醒/收件箱|改期版本失效重算、发送前核验、闭页recorded/read、持久Delivery|无Web Push/系统弹窗；userReceived unknown；敏感核验失败抑制，不发送旧正文|
|只读Agent简报|到点原Task、固定Bot/来源/提示/额度、结果/用量与原Task链接|仅只读；无自动写/委派；失败/unknown停等原Task，不创建新Task盲重试|
|工作区|待办/日历/定时任务/执行记录/通知/来源状态/助理会话；权限统一在 Bot 页，stdio 凭证在设置页|删除独立 AgentWorkspace 面板；“日历”为本地/外部事件清单与时间窗口；没有新增拖拽、完整月视图或连接器|


## 运行条件与非承诺
后台进程必须在线；网页可关闭。一个后端独占一个 SQLite 库。仅本机单 owner，不提供多租户隔离产品保证；历史真实跨租户验收豁免不转为通过。

外部 provider 不提供原子 CAS 或通用 exactly-once 保证；unknown 必须保留。通知 recorded/read 不代表用户实际收到。没有云端部署、手机 App、Web Push、邮件/外部待办连接器、支付和完整长期记忆系统。
