# Pidot v3.0.0

发布日：2026-11-02（Asia/Shanghai）

**把想法变成行动，让协作持续积累。**

Pidot v3 把个人助理的核心体验收进一个本地工作台：和 pipi 讨论目标，找不同的机器人一起推进，在日历中安排时间，让偏好与经验留在后续协作里。

## 这一版的亮点

- **更自由的机器人团队**：只需名字即可创建空白机器人，按需配置职责、人格、模型与能力；普通机器人使用一致的能力规则。
- **更完整的协作链路**：任务委派、结果回交、验收与返工、群聊定向协作，结合阻塞处理与来源记录。
- **更连贯的对话**：独立主会话、会话列表、Markdown 渲染、折叠工具调用、问题表单与能力即时同步。
- **更持久的积累**：每个机器人的人格与记忆、共享偏好、本地 Markdown 编辑、历史搜索、后台整理，以及将验证过的方法沉淀为 Skill。
- **更灵活的模型配置**：多个 OpenAI 兼容供应商与模型登记、机器人模型选择、思考深度与上下文容量、上下文压缩。
- **更集中的日常管理**：事项页整合日历、定时任务、执行记录；通知页收拢需要处理的确认、提问与提醒。
- **更清楚的能力入口**：Skills / MCP / 工具集统一管理，文件与命令能力默认具备，连接配置和模型凭证留在服务端。
- **更完整的项目展示**：全新中文 README、五张实际界面截图、快速开始与功能状态说明。

界面预览与安装步骤见[项目首页](../../README.md)。截图来自隔离演示环境，使用示例回复和虚构事项。

## 安装与升级

新用户按[快速开始](../../README.md#快速开始)获取 `v3.0.0`。需要 Node.js ≥ 22.22.1、pnpm 11.21.0。

已有用户升级前先停止旧服务，备份整个数据目录（默认 `my-app/data/`，包括数据库、记忆、Skills 及连接凭据），更新后重新构建启动。旧配置可能在首次启动时自动迁移，详见[运行手册](../engineering/operations.md#第四轮升级r4)。备份属于本机私有数据，请勿上传 GitHub。

## 当前范围与后续方向

v3 面向本地单用户，服务绑定 `127.0.0.1`。后端在线时可执行定时任务，浏览器可以关闭；通知目前保存在应用内。

飞书、Google 和外部 MCP 的使用需要配置相应连接与机器人能力。Google 真实账号、飞书真实写入与后台学习的长期质量仍待完整验收；版本发布不代表这些验收已经完成。

长任务持续执行已完成规划，尚未实现。后续将沿着清晰的任务推进、可恢复执行和更稳定的长期协作继续演进。当前计划与状态见 [NEXT_STAGE](../../NEXT_STAGE.md) 和[实施计划](../../plans/README.md)。
