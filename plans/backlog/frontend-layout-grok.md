# 前端布局优化（Grok 风格）

## 目标
把现在“顶部 Tab 工作区 + 会话页内再嵌侧栏”的两层结构，改为类 Grok 的单一对话中心布局：左侧可折叠导航栏、中间居中对话流、底部固定输入框，工作区页面变成侧栏入口/右侧抽屉。不改后端接口与业务语义。

## 现状问题
- UnifiedWorkspace 8 个顶部 Tab 与 App 内会话侧栏重复导航；默认落在“待办”而不是会话。
- 新建会话（Bot 卡片网格）和会话详情纵向堆叠在同一页，对话不是主角。
- 状态徽章逻辑是一长串三元表达式（App.tsx:407），难以复用到新布局。
- 样式集中在单行压缩的 App.css，断点分散（1000/720/700/600/480）。

## 目标布局
- 左栏（260px，可折叠为图标栏 64px）：新建会话按钮、会话搜索、按时间分组的会话列表（今天/昨天/更早）、Bot/群聊筛选、底部“工作区”入口组（待办、日历、定时任务、执行记录、通知、审批、来源）。
- 主区：空会话时显示居中问候 + 大输入框 + Bot 选择 chip（取代卡片网格）；有会话时为居中 760px 消息流 + 底部吸附输入框，状态徽章放在顶部细条。
- 右侧抽屉（可选）：会话身份/用量/权限/审批等现在的 details 区块移入，默认收起。
- 工作区页：在主区整页打开，保留现有组件和“面板常驻不卸载”约束。
- 移动端（<720px）：左栏变抽屉，输入框底部固定，安全区适配。

## 分步实施
1. 抽取：把状态徽章逻辑抽成 `taskStatusLabel(task)`；App.tsx 拆出 Sidebar、ChatView、Composer、NewChatHero 组件（纯重构，行为不变）。
2. 外壳：新建 AppShell（左栏 + 主区 + 抽屉），UnifiedWorkspace 改为由左栏驱动视图，去掉顶部 Tab；保留 hash 路由与键盘可访问性（导航改为 nav 列表 + aria-current）。
3. 对话视图：消息流居中、输入框 sticky、自动滚动到底、发送中状态；Bot 卡片改为输入框上方 chip/下拉。
4. 详情抽屉：身份、用量与权限、审批、阻塞、取消等控件迁入右侧抽屉，审批/阻塞待处理时在消息流内保留醒目提示卡。
5. 样式：App.css 展开为分文件或分段，引入 CSS 变量（颜色/间距/圆角），可选深色主题（Grok 风格偏深色，需确认）。
6. 响应式与可访问性：统一断点 1000/720；焦点管理、折叠按钮 aria-expanded、抽屉 Esc 关闭。
