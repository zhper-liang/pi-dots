## 1. Hermes 风格统一（新增最高优先级视觉工作）

### 目标

以用户提供的 Hermes 截图为**布局与视觉语言参考**，统一现有 Pidot，不复制 Hermes 品牌、文案、紫色吉祥物或文件树功能。保留 Pidot 的 Bot、群聊、权限、审批、事项与本地来源语义。

### 布局

- 桌面采用「左侧导航 / 中央内容 / 可选右侧上下文栏」三栏。左侧约 248–272px，可折叠；中央对话最大宽度约 760–860px；右栏默认隐藏，按需展示任务、审批、来源、身份和连接详情。
- 左栏顺序：Pidot 标识与新建会话；会话 / 机器人主切换；搜索；置顶与按时间分组的会话；底部事项、通知、设置。Chief 是主会话入口，不再单独制造一个“今天”目的地。
- 空会话为轻量居中的 Pidot 品牌与提示语，不使用巨大 HERMES 字样或复制吉祥物。新建会话在同一中央输入流选择 Bot / 群聊。
- 输入框在对话底部吸附，内部保留 Skill、群 @ 收件人、模型、思考深度、发送和停止；高级项收进紧凑菜单。发送中、插入、排队状态必须可区分。
- 右栏是辅助信息，不承载唯一可完成的审批/阻塞操作；这些操作在主消息流保留醒目卡片。移动端左右栏都是抽屉，不出现横向滚动。
- 事项、Bot 详情、模板、设置使用同一外壳和标题层级，不再出现顶部 Tab 与嵌套侧栏重复导航。

### 视觉系统（2026-10-28 按两张截图实测）

参考图：`.scratch/hermes-workspace/ref/skills-page.png`（主界面）、`settings-modal.png`（设置弹窗），本地保存，不进仓库。

**一句话：界面退到纸面后面，层级靠字号和灰阶，不靠框线和颜色；整个界面只有一种亮蓝，只用来标「选中了什么、开着什么」。**

像阴天上午的书桌，冷、白、安静。侧栏是一张浅灰纸，正文区是一张白纸，两者只差几个百分点的亮度，中间没有分隔线。卡片几乎看不见，靠一条淡到快没有的描边和一点灰度浮出来；没有阴影，什么都不抢眼。信息密度分两档：侧栏紧凑，一行一项，标题下挂一行小灰字元信息；正文区像杂志，大标题、大留白，内容自己说话。设置页像账本：左边是标签，右边是控件，行与行之间只靠留白分开。亮蓝很浓但很省，只出现在选中的筛选标签、开关、标签页下划线和侧栏分组小标题上；侧栏选中项反而用淡蓝灰底加一圈细蓝边，不用浓蓝。文字不用纯黑，分四档灰。角几乎是直的，只有开关和搜索胶囊是全圆。字小而笃定，正文 13–14px，只有页面标题和分区标题明显放大，也不加装饰。

### C. 统一事项、日历与例行任务

- 合并自动化、待办、日历、执行记录为「事项」；删除独立「今天」入口，今天的内容放进「事项」默认视图（日视图 + 今天到期待办），检测卡仍进 Chief 主会话；Chief 主会话保留。
- 通知分「需要你处理」和「事项提醒」，只展示标题、时间、原因、动作和原 Task，技术 ID 放诊断。
- 日历日 / 周 / 月和桌面端本地拖动改期已存在（`CalendarBoard.tsx`）；补待办同屏，窄屏沿用点击后编辑时间改期，不做触屏拖动。改期使用 `expectedVersion + requestId`，不乐观覆盖。飞书仍按来源限制只读。
- 周期支持一次、每日、每周、每月、间隔、时区；明确 DST、月末、暂停不补跑。月末规则执行前先问用户（见 §0.5）。不做自然语言周期解析：对话里由 `routine_propose` 生成例行任务，表单只收结构化字段。新增周 / 月类型后回滚到旧代码会被 `normalizeScheduleRule` 拒绝，票里写明回滚边界。
- 表单含名称、执行 Bot、提示词、频率、时区、可选模型、通知开关。结果回执关联 Bot 会话和应用通知，不声称已发微信 / QQ / 系统推送。

### D. 三文档与模型设置

- 每个 Bot 一份人格、一份记忆，所有 Bot 共用一份用户偏好；都带版本、更新时间、来源引用和编辑历史；人格仅用户编辑。共用偏好的并发更新用 `expectedVersion`。
- 偏好和记忆在会话空闲或上下文压缩时批量、幂等、限额更新（单独调用额度），不每轮多调一次模型，不阻塞原回复、不重放工具。候选补丁服务端校验，失败保留旧文档并显示待处理。
- 记忆过滤凭证和无来源推测；即将发生的日程实时查询，冲突以日历为准。上下文注入有界，压缩保留事实、结论、来源、未完成事项和已完成工具效果。
- 模型设置保存 Base URL、模型名、API key；环境配置优先且在 UI 明示。Task 只记模型名，地址和 key 每次调用实时读取：保存后对所有会话（含旧 Task、例行任务）的下一次调用生效，不需要重启；旧模型名在新服务商不存在时明确报错。服务商名称不再写死 `bb-api`；Bot 配置版本哈希目前包含模型地址（`bots.mjs:23`），改地址不能因此触发配置迁移提示。key 存 `data/` 下单独的 0600 文件，不进 SQLite。URL 只允许 HTTPS 或 loopback HTTP，key 永不回显，前端保存后清空。
