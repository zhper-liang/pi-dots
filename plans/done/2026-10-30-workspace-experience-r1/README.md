## 简单与复用原则

1. 沿用 React、Node、Harness、SQLite、现有 Task/Schedule/Operation 与权限裁决，不新增数据库、任务引擎、事件总线框架或插件平台。
2. 复用 `CommandMenu`、`Switch`、`SystemCard`、日历网格/弹窗、`routines` 规则与现有模型配置。仅在至少两处确需复用时抽小组件/纯函数，不先造通用表单/全站状态框架。
3. 一处配置权威：工具分配用现有 `ToolAccess`；新增 MCP/Skill 元数据只存现有结构缺的内容。UI 和 Agent 调用同一后端服务。
4. MCP 优先复用经确认的官方客户端 SDK，不手写另一套完整协议；若必须新增依赖，在启动前一次性说明并确认，未确认不安装。现有内部 MCP client 不冒充通用第三方连接器。
5. 安装配置 ≠ 分配给 Bot ≠ 执行外部写入。用户明确“给某 Bot 添加某能力”可以一次完成配置和绑定，不再强迫填表；外部文档不能自行扩大授权。
6. 原有 Bot、任务、来源与记忆兼容保留；只调整新 Bot 默认值。不因“不要待办”删旧数据，不用归档冒充删除，不用 allow/ask 冒充启用/禁用。
