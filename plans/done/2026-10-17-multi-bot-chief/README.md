# 多 Bot 与 Chief 管理（已完成）

完成日期：2026-10-18 · 6 票全部完成 · 联合验收 486 项回归 + 真实模型通过。

## 目标

用户可以创建专业 Bot 并持续独立对话，管理版本化配置与能力授权，在安全边界迁移旧会话，停用 Bot 并保留真实结果；Chief 通过对话复用这些管理能力。

## 交付内容（6 票）

| 票 | 交付 |
|---|---|
| 01 | 创建 Bot 并持续独立对话 |
| 02 | 配置 Bot、授权能力并即时撤权（默认空池、独立分配、版本/CAS；411/411） |
| 03 | 旧会话安全迁移到新配置（只在无执行、无待消费输入、无等待事项时） |
| 04 | 停用 Bot 并保留历史与在途结果（持久停用、派发拦截、迟到回执；467/467 全量） |
| 05 | Chief 通过对话完成 Bot 创建、调整与停用 |
| 06 | 多 Bot 与 Chief 管理联合验收 |

## 关键决策

- 沿用骨架期的 Harness Task/conversation/Document，不重开旧 23 票、不建平行状态机。
- 停用不等于取消或删除；保留迟到回执与未知结果，本轮不重新启用。
- 能力池扩池必须由认证用户显式操作，Chief 不能自行扩池；撤权即时复查，新增授权不自动扩张旧 Task。
- 恢复不等于重新授权。

## 边界

不含跨 Bot 协作/群聊、真实连接器、定时与事件触发、完整记忆或整体 UI 改版。
