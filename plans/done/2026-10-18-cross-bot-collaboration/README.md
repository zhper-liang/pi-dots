## 目标

任意获准协作的 Bot 可作为入口与主管，向已有专业 Bot 发起一层委派：独立子线程、受限共享信息、主管/用户处理阻塞、精确审批危险操作、提交/返工/验收形成可追溯闭环；断线或重启后不丢状态、不越权、不重复副作用。

## 关键边界

- 复用既有 Task/conversation/Document 与运行保护，执行者自己的权限不因主管身份扩大。
- 只做一层委派；完整群聊/@、同步 consult、深层委派不在本轮。
