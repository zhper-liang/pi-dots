完成日期：2026-10-19 · 6 票全部完成 · 最终 183 专项 / 742 全量、lint/build、真实对话与双尺寸网页验收通过。

## 目标

把飞书应用身份日历接入 Pidot：只读连接、审批后创建/更新/删除、忙闲与可用时段、Pidot 图形日历与统一安全编辑。

## 交付内容（6 票）

| 票 | 交付 |
|---|---|
| 01 | 应用连接、日历绑定与只读闭环 |
| 02 | 日程创建、精确审批与未知结果恢复 |
| 03 | 日程更新、删除与冲突核验（持久事件租约） |
| 04 | 应用日历忙闲与可用时段（21 GET / 0 写实测） |

| 06 | 真实日历群聊联合验收与交接 |

## 关键边界

- 飞书只作应用身份日历存储；Pidot 负责对话与日/周视图。
- 首轮只做普通单次事件写入；重复/全天事件按读取处理。
- 如实保留未证限制：租户切换实测属用户豁免、unknown 删除不自动重试、外部 CAS 无原子保证。
