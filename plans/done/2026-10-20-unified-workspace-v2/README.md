## 关键结论

- 五个概念要分清：Bot（谁来做）、Harness Task（怎么执行）、业务对象（日程/待办/计划）、来源（local/飞书）、Operation（受控写入）。
- 同步取外部事实、计划决定何时动作、检测器从结构化事实发现问题；普通提醒和检测不调用模型。
