# 普通 Bot 平等与空白创建

状态：2026-11-01 实现与验证完成，待用户验收。test 1540/1540、lint/build 通过；1440 / 375 界面走查通过。本地改动未提交，正式库未操作、正式服务未重启。

依据：“bot除了主管应该地位都一样，创建bot也应该默认空白bot开始而不是必须选择模板”。当前规则见 [ADR-023](../../../docs/decisions/README.md#adr-023-普通-bot-地位相同默认空白创建)。

## 范围

- 除主管外，预置与自建 Bot 按同一套当前能力分配、配置和停用规则运行。
- 新建默认名字/职责不预填、能力全关；只需名字即可创建。网页、HTTP、主管代建一致。
- 模板折叠为可选项，可恢复空白，不授予身份或永久特殊权限。
- 旧普通 Bot 主会话隐式能力一次转为普通分配，保留原权限与撤销，后续关闭和重启不恢复。
- 旧 Bot 配置、任务、创建回执不被新默认值重写；不操作正式库，不增依赖，不派子 agent。

## 验收

- 同配置的预置与自建普通 Bot 权限一致；关闭能力后立即生效且重启保持。
- 主管仍可管理，不能停用自身；普通 Bot 可按相同规则停用。
- 空白直接创建、模板预填与恢复空白、能力目录读取失败、提交重试与重复点击均可用。
- 全量 test、lint、build；1440 / 375 两种宽度创建与设置走查。

执行证据保存在 `.scratch/bot-equality/`（本地，不进仓库）。

## 验证结果

- `pnpm test`：1540/1540；覆盖网页/API/主管空白默认、同配置普通 Bot 权限一致、移除能力后重启不恢复、旧 R4 创建回执原样重放。
- `pnpm lint`：通过，10 条既有 warning，无新增。
- `pnpm build`：通过，保留既有较大 bundle 提示。
- 1440 / 375 页面走查：仅名字创建、模板预填及恢复空白、预置/自建设置与停用入口、能力目录读取失败、创建回执丢失后的原 requestId 重试均通过，无横向溢出或页面异常。
- 旧普通 Bot 固有权限实体化后，单独持有定时提案工具不授予日历/任务列表；普通任务迁移跳过主会话专属工具，已有回归通过。
