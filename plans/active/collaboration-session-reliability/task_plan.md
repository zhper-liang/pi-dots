# 协作、会话与模型故障修复

2026-11-01：用户要求检查实际会话中结果不可见、聊天历史和模型切换失败，并改善机器人目录与过度谨慎。本地实现和验证完成；真实模型拒绝原因已定位并通过最小真实请求验证修复；正式会话恢复仍待验证。

1. 对照实际会话与服务端来源检查，修复普通委派的派发、续跑与结果默认交付，以及同 Bot 独立任务的结果摘要；接收者的直接来源选项不限制结果交付，保留作者来源撤销和群聊共享边界。
2. 会话列表展示已有活动的机器人主会话，保持原 Task 身份与历史，并保护主会话的清空语义。
3. 提供精简的实时机器人目录和当前时间，消除不必要的等待；不猜测服务商拒绝原因。
4. 定向测试、全量测试、lint、隔离构建与运行记录；验证模型选择的界面标签不进入供应商请求；不自动改写真实会话或重启正式服务。
